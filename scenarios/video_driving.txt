# 开车场景（60s，循环执行）
# 语法：<持续秒数> : <命令1> ; <命令2> ; ...
#
# 五段行驶状态：
# 1) 地下车库出口（0-10s）——信号遮挡/多径：带宽缩水 5M + 随机丢包 2%
#    + 延迟抖动大（均值 25ms、3% 概率 80-200ms 长尾——FEC 要覆盖的
#    深度掉队报文）+ 报告丢失 20%（链路严重卡顿——发送端报告超时
#    检测触发 btl 乘性下降）
# 2) 人群密集（10-20s）——无线频谱拥塞：带宽受限 10M + L4S 启用
#    （队列积压超 20ms 即 CE 标记，传输协议提前降速而非丢包）
# 3) 正常网络（20-30s）——满带宽干净链路，btl/码率回升
# 4) 郊区信号弱带宽不足（30-40s）——稳定但只有 4M 带宽，延迟略升；
#    L4S 开启让发送端感知带宽下限（否则 btl 无感，视频硬塞积压）
# 5) 恢复正常（40-60s）——满带宽干净链路 20s
