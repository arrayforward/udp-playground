# 视频跟随性测试（总 40s，循环执行）：
#   良好(8s) -> 差(8s) -> 良好(8s) -> 稍差(8s) -> 良好(8s)
# 验证：btl 带宽估计、视频码率自适应、动态迟到线 FEC 的跟随性
#       以及弱网切换时的延迟/卡顿效果。
# 语法：<持续秒数> : <命令1> ; <命令2> ; ...
# 未指定的参数继承上一段；循环回到第一段时恢复启动参数。

# 段1：良好（8s）——无延迟、无丢包，高带宽
8: bw 10000000; loss 0; delay-off; reorder-prob 0

# 段2：差网络（8s）——延迟均值 10ms σ1ms，2% 长尾 +50~200ms，中度丢包
# 弱网最低带宽 3000K（3Mbps）：与 QSV 720p 编码下限（1.5M）拉开余量，
# 弱网段不再被编码下限顶穿超发
8: bw 3000000; loss 0.02; delay-normal 10 1 0.02 50 200

# 段3：良好（8s）——恢复
8: bw 10000000; loss 0; delay-off; reorder-prob 0

# 段4：稍微差网络（8s）——延迟均值 10ms σ1ms，1% 长尾 +50~150ms，轻度丢包
8: bw 4000000; loss 0.01; delay-normal 10 1 0.01 50 150

# 段5：良好（8s）——恢复
8: bw 10000000; loss 0; delay-off; reorder-prob 0
